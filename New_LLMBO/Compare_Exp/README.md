# Compare_Exp

Curated archive for `ParEGO` and `LLMBO` comparison materials.

## Folder Structure

- `images/`: exported figures in `png` and `pdf`
- `reports/`: manifests, summary reports, and overview documents
- `experiment_records/`: run snapshots including `summary.json`, `pareto_front.json`, `db_final.json`, and `database.json`

## Naming Convention

Folder names use:

`YYYY-MM-DD_scope_experiment_description`

Examples:

- `2026-05-06_seed8409_single_seed_parego_reference_localstd`
- `2026-05-06_five_seed_optimal_protocols`
- `2026-05-02_seed8409_ten_iter_model_comparison`
