\section{Experimental Validation}
\label{sec:experiments}

\subsection{Models, LLM Configuration, and Fixed-Budget Protocol}

All objective values are simulated with the model in Section~\ref{sec:model}
using the Chen2020~\cite{ref12,ref13} or Ecker2015~\cite{ref12,ref14}
parameterization; no physical measurement enters an archive.

Each paired seed (8409--8413) uses six initialization and 50 BO evaluations.
The main configuration uses three screened LLM and three random points.
Chen2020 uses
\texttt{deepseek-v3}, whereas Ecker2015 uses
\texttt{deepseek-v3-thinking}; both use an OpenAI-compatible interface,
temperature zero, and one completion. Because parameterization and backend
change together, this is not an isolated transfer test.

\subsection{Baselines, Metrics, and Reproducibility}

ParEGO~\cite{ref5} uses the archived MATLAB-reference scalarization and
acquisition settings. The Chen2020 comparison additionally includes
NSGA-II~\cite{ref6}; its 60-evaluation trajectory is truncated at evaluation
56 for the fixed-budget comparison.

For reporting, define
\begin{equation*}
\widetilde{\mathbf f}=
\left[
\log_{10}\!\left(\frac{t_c}{1~\mathrm{s}}\right),\,
\Delta T_p,\,
\log_{10}\!\left(\frac{D_{\mathrm{chg}}}{1~\mathrm{a.u.}}\right)
\right]^\top .
\end{equation*}
For benchmark $b$, benchmark-scaled hypervolume (sHV) is
\begin{equation}
\mathrm{sHV}_b(\mathcal P)=
\frac{\mathrm{HV}(\widetilde{\mathcal P};\widetilde{\mathbf r}_b)}
{\prod_{i=1}^{3}(\widetilde r_{b,i}-\widetilde z_{b,i})}.
\label{eq:scaled_hv}
\end{equation}
Chen2020 uses reporting ideal/reference points
$[1800,0,0.3]$ and $[7200,40,5]$; Ecker2015 uses
$[2500,0,0.2]$ and $[7000,35,4.5]$. These fixed reporting boxes are distinct
from the dynamic normalization used by the optimizer. No clipping is applied,
so sHV is dimensionless and may exceed one. Absolute sHV values are comparable
only within a parameterization~\cite{ref25}. We report five-seed means and sample standard
deviations without inferential significance or equivalence claims.

\subsection{Runtime and Evidence Limitations}

Chen2020 runtimes are $252.4\pm17.7$~s for ParEGO and $440.3\pm31.3$~s for
LLMBO-MO. Missing hardware and software metadata preclude a portable benchmark.
Evidence is limited to two simulations, five seeds, an uncalibrated proxy, and
different LLM backends. It establishes neither long-term cycling nor
physical-cell behavior. The active lift is evaluated only in the Chen2020
same-batch study.
